## What is LightVela?

[LightVela](https://lightvela.ai/?ref=688JVXCZKD) is a cloud-hosted AI agent platform (built by Tencent Lighthouse). You create an AI assistant in the browser, connect it to Telegram / WhatsApp / Discord / Slack, and it keeps running 24/7 in the cloud — no server, no code, no keeping your laptop on.

Think of it as giving an AI a permanent desk in the cloud instead of a tab in your browser.

## The Good

- **Fastest agent deploy I've tried.** Idea to talking Telegram bot in under 15 minutes.
- **Truly always-on.** Scheduled tasks, reminders, and chat all run server-side. Close your laptop, it keeps working.
- **Multi-channel out of the box.** Telegram, WhatsApp, Discord, Slack — connect several at once.
- **Honest free tier.** 4,500 credits/month free for a month, no card required upfront.
- **Confirm-before-acting.** It asks before doing anything destructive — a small thing that matters a lot for an agent with chat access.

## The Rough Edges

- **The vault won't take bank cards.** I tried to store payment credentials for auto top-ups; the agent refused to handle raw card numbers. Understandable from a security standpoint, but it means no fully automated billing yet.
- **Model choice is thin right now.** The picker effectively offers "auto" — no way to pin a specific model per agent today.
- **Docs are still maturing.** Some features (like the referral program) exist but aren't easy to discover — I had to dig.

None of these are dealbreakers for a v1 product, but worth knowing before you dive in.
